¿Qué es HTML?

HTML (HyperText Markup Language) es el lenguaje de marcado utilizado para crear la estructura básica de una página web. Todas las páginas web utilizan HTML para definir elementos como párrafos, enlaces, imágenes y otros componentes.

Estructura básica de un documento HTML

Un documento HTML básico contiene las siguientes partes:


<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Título de la página</title>
</head>
<body>
    <h1>Encabezado principal</h1>
    <p>Este es un párrafo.</p>
</body>
</html>

Etiquetas de estructura

Etiqueta Descripción Ejemplo
<html> Define el documento HTML <html lang="es">...</html>
<head> Define información sobre el documento <head>...</head>
<body> Define el cuerpo del documento <body>...</body>
<header> Define un encabezado para un documento o sección <header>...</header>
<footer> Define un pie de página para un documento o sección <footer>...</footer>
<section> Define una sección en un documento <section>...</section>
<article> Define contenido independiente y autosuficiente <article>...</article>
<aside> Define contenido aparte del contenido principal <aside>...</aside>
<nav> Define enlaces de navegación <nav><a href="#">Inicio</a></nav>
<main> Define el contenido principal del documento <main>...</main>

Etiquetas de texto

Etiqueta Descripción Ejemplo
<p> Define un párrafo <p>Este es un párrafo.</p>
<h1> a <h6> Define encabezados HTML (de mayor a menor importancia) <h1>Título</h1>
<strong> Define texto importante (en negrita) <strong>Texto importante</strong>
<em> Define texto enfatizado (en cursiva) <em>Texto enfatizado</em>
<b> Define texto en negrita <b>Texto en negrita</b>
<i> Define texto en cursiva <i>Texto en cursiva</i>
<small> Define texto pequeño <small>Texto pequeño</small>
<mark> Define texto resaltado <mark>Texto resaltado</mark>
<blockquote> Define una sección citada de otra fuente <blockquote>Texto citado</blockquote>
<q> Define una cita corta <q>Texto de cita</q>
<pre> Define texto preformateado <pre>Texto preformateado</pre>

Etiquetas multimedia

Etiqueta Descripción Ejemplo
<img> Define una imagen <img src="imagen.jpg" alt="Descripción">
<audio> Define contenido de sonido <audio controls>...</audio>
<video> Define un video embebido <video controls>...</video>
<source> Define un recurso multimedia para <video> o <audio> <source src="video.mp4" type="video/mp4">
<track> Define texto de pista para medios <track kind="subtitles" src="subtitulos.vtt" srclang="es">
<canvas> Utilizado para gráficos de dibujo <canvas id="miCanvas"></canvas>

Etiquetas de listas

Etiqueta Descripción Ejemplo
<ul> Define una lista desordenada <ul><li>Elemento 1</li><li>Elemento 2</li></ul>
<ol> Define una lista ordenada <ol><li>Elemento 1</li><li>Elemento 2</li></ol>
<li> Define un elemento en una lista <li>Elemento de lista</li>
<dl> Define una lista de descripción <dl><dt>Término</dt><dd>Descripción del término</dd></dl>
<dt> Define un término en una lista de descripción <dt>Término</dt>
<dd> Define una descripción en una lista de descripción <dd>Descripción del término</dd>

Etiquetas de formularios

Etiqueta Descripción Ejemplo
<form> Define un formulario HTML para entrada del usuario <form action="submit.php">...</form>
<input> Define un control de entrada <input type="text" name="nombre">
<textarea> Define un área de texto multirenglón <textarea>Texto aquí</textarea>
<button> Define un botón clicable <button>Enviar</button>
<label> Define un rótulo para un elemento en un formulario <label for="nombre">Nombre</label>
<select> Define un control de menú desplegable <select><option>Opción 1</option></select>
<option> Define una opción en un menú desplegable <option>Opción 1</option>
<fieldset> Agrupa controles relacionados en un formulario <fieldset>...</fieldset>
<legend> Define un título para el elemento <fieldset> <legend>Título del formulario</legend>

Ejemplo de HTML en acción

El siguiente es un ejemplo de una pequeña página HTML:


<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Mi primera página web</title>
</head>
<body>
    <h1>Bienvenidos a mi página web</h1>
    <p>Esto es un párrafo de ejemplo.</p>
    <a href="https://www.google.com">Visitar Google</a>
</body>
</html>

Comentarios en HTML

Para hacer un comentario en HTML utilizamos la estructura " <!--- (Texto) ---> ", los comentarios sirven para ayudarnos a nosotros como programador o a las personas que leen nuestro código, teniendo una breve descripción. Los comentarios no se ejecutan ni se muestran en la página web.

¿Dónde es más recomendado programar en HTML5?

La herramienta que se recomienda utilizar para programar HTML es un editor de texto llamado "Visual Studio Code", esta proporciona compatibilidad básica con la programación HTML lista para usar. Hay resaltado de sintaxis, finalizaciones inteligentes con IntelliSense y formato personalizable. VS Code también incluye un gran soporte de Emmet.
