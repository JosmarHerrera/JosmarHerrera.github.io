¿Qué es JavaScript?

JavaScript es un lenguaje de programación que permite agregar interactividad a las páginas web. Con JavaScript, puedes hacer que los elementos reaccionen a las acciones del usuario, como clics, desplazamientos y formularios.

¿Cómo funciona JavaScript?

JavaScript puede ejecutarse directamente en el navegador, sin necesidad de ningún software adicional. Se puede insertar directamente en el HTML usando la etiqueta <script> o mediante un archivo JavaScript externo.

JavaScript se ejecuta en el lado del cliente, lo que significa que el código se procesa en el navegador del usuario.

Tipos de datos en JavaScript

JavaScript tiene varios tipos de datos:

  • String: Cadenas de texto (por ejemplo, "Hola Mundo")
  • Number: Números (por ejemplo, 42)
  • Boolean: Verdadero o falso (true o false)
  • Array: Lista de valores (por ejemplo, [1, 2, 3])
  • Object: Colección de propiedades (por ejemplo, { nombre: "Josmar", edad: 25 })
  • Null: Valor nulo, representa la ausencia de valor.
  • Undefined: Variable no definida.

Funciones JavaScript comunes

  • alert(): Muestra una alerta emergente.
  • console.log(): Muestra mensajes en la consola del navegador.
  • document.getElementById(): Selecciona un elemento HTML por su ID.
  • addEventListener(): Añade un evento a un elemento.
  • parseInt(): Convierte una cadena a un número entero.
  • parseFloat(): Convierte una cadena a un número de punto flotante.
  • Math.random(): Devuelve un número aleatorio entre 0 y 1.
  • Math.floor(): Redondea un número hacia abajo.

Ejemplo de JavaScript

Este es un ejemplo de cómo usar JavaScript para mostrar una alerta al hacer clic en un botón:


<button onclick="saludar()">Haz clic aquí</button>

<script>
    function saludar() {
        alert("¡Hola, bienvenido!");
    }
</script>

Estructuras de control

JavaScript incluye estructuras de control como:

  • Condicionales: 
    
if (condición) {
    // código a ejecutar si la condición es verdadera
} else {
    // código a ejecutar si la condición es falsa
}
  • Bucles: 
    
for (let i = 0; i < 5; i++) {
    console.log(i);
}

while (condición) {
    // código a ejecutar mientras la condición sea verdadera
}

Manipulación del DOM

JavaScript permite manipular el Document Object Model (DOM) de la página:

  • document.createElement(): Crea un nuevo elemento HTML.
  • appendChild(): Agrega un nuevo nodo como hijo de un nodo existente.
  • removeChild(): Elimina un hijo de un nodo.
  • innerHTML: Permite modificar el contenido HTML de un elemento.
